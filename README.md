# Whitee

주아케 SD 놀이방. 큰 SD 조커와 아케치를 집고, 흔들고, 던지고, 이것저것으로 놀리며 구경하는 웹 장난감이에요.

`index.html` 하나로 동작해요. 브라우저로 열거나 GitHub Pages로 배포하면 돼요.

- 손: 머리를 잡아 들기, 꼬리를 잡아 거꾸로 매달기, 톡 눌러 콕 찌르기
- 쓰담: 머리 위를 살살 문지르면 조커는 바로 녹고, 아케치는 버티다가 넘어가요
- 분무기 · 깃털 · 바람 · 기울이기 · 장난감 · 간식(한 번 더 누르면 함정 간식)
- 소품: 커피잔, 상자, 쿠션, 바나나 껍질, 투명 컵
- 우측 상단: 바닥 흔들기, 처음 장면, UI 숨기기
